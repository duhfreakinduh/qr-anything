How this differs from the regular transfer

This optical mode does not use WebRTC, TURN, Wi-Fi, cellular data, Bluetooth, or a device-to-device network path for the file. The website must be loaded first, but once its assets are cached the payload itself travels only as visible QR light. Optical frames are not encrypted—another camera that can see the sender screen can capture them too.
