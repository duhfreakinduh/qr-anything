HOW IT WORKS

Private transfer without uploading your files

1

Pair

The sender and receiver exchange connection details through animated QR codes.

2

Connect

WebRTC creates an encrypted browser-to-browser data channel. Files are not stored by this app.

3

Transfer

Messages and file bytes move directly between the two devices with live progress.

Important limitation

Very large transfers depend on browser memory and network conditions. The app can use cellular data, different Wi-Fi networks, or the same network. When a direct connection is blocked, an encrypted TURN relay carries the transfer. QR-only mode remains limited because video-sized data would require thousands of QR frames.
